# Default community health files

Account-wide defaults for repositories owned by [4uva4ek](https://github.com/4uva4ek).
GitHub applies files from this repository to every repository that does not have its
own copy of the same file.

- `.github/FUNDING.yml` adds the Sponsor button with the Ko-fi link.

A repository that needs different links can override this by adding its own
`.github/FUNDING.yml` on its default branch.
